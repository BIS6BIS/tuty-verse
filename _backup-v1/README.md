# Tu’s Journey: a fan-made birthday game 🌻

A non-commercial fan gift celebrating Tu Tontawan Tantivejakul. Not affiliated with Tu, her agencies, broadcasters or any studio. Photos are linked from their original sources.

## Files
- `index.html`: page structure (console, start screen, map, mailbox)
- `style.css`: all styling, light and dark themes, mobile layout
- `script.js`: stage data, map, gallery, mailbox and fan wishes

## Editing content
- **Stages:** edit the `STAGES` list near the top of `script.js`.
- **Fan wishes:** paste rows from Excel into `EXCEL_ROWS` in `script.js` (columns: handle, name, message, badge).
- **Google Form link:** set `FORM_URL` in `script.js`.
- **Hidden words:** add them to `BLOCKLIST` in `script.js`.

## Run locally
Open `index.html` in a browser, or use the VS Code “Live Server” extension.
